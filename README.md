## Networking Projects

The following projects form my network engineering portfolio, focusing on enterprise infrastructure, automation, security, and cloud networking.

**Project Scope:**

### 2. Automated Network Configuration & Compliance Management

**Technologies:** Python, Ansible, Netmiko, Jinja2, Git, Cisco IOS

**Project Scope:**
- Develop Python scripts and Ansible playbooks to automate network configuration deployment and device management.
- Use Jinja2 templates to standardize configurations across Cisco routers and switches.
- Implement automated configuration backups, Git version control, and configuration compliance checks.

### 3. Enterprise Firewall Deployment & Network Segmentation

**Technologies:** pfSense, Proxmox, EVE-NG, NAT, VPN, Wireshark

**Project Scope:**

- Configure stateful firewall policies, NAT, VPN access, and network segmentation.
- Analyze firewall logs and packet captures to validate security policies and troubleshoot network connectivity.

### 4. Azure Hub-and-Spoke Network Architecture

**Technologies:** Microsoft Azure, Virtual Networks, VNet Peering, NSGs, Network Watcher

**Project Scope:**
- Design an Azure hub-and-spoke network architecture with isolated production and development environments.
- Configure VNet peering, subnet segmentation, and Network Security Groups to control traffic.
- Validate network connectivity and troubleshoot security restrictions using Azure Network Watcher.
